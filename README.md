cmd-expenses-tracker - IT-566 Computer Scripting Techniques

This software is a Python-based Command-Line Application for User's Personal Expense Records Management.

The Features include:

-Adding an expense (with date, category, cost and description)
-Viewing all added expenses and calculating total costs
-Filtering expenses based on categories, dates, or both categories & dates
-Saving added expenses to JSON format files 
-Opening previously saved JSON format files
-Exporting added expenses to CSV format for use in MS Excel

Project Structure:

main.py – Main Program/Command Line Interface for User Input/Output

expenses.py – Contains Functions for Input/Output of Expenses as well as Filtering of Expenses

storage.py – Contains Code for Working with JSON & CSV Format Files

How to Use this Software:

Open a New Terminal Window from within Your Project Directory and Type ‘python main.py’

Type ‘HELP’ Into Your Terminal Window If You Want To View All Available Commands.

cmds:

ADD, LIST, FILTER, SAVE, OPEN, EXPORT , HELP, EXIT
